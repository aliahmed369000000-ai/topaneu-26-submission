## البنية المعمارية المتفق عليها (Task 1)

- Backbone v1: طبقة Conv واحدة/مرحلة، 5 مراحل، 128³→...→4³→GAP→2048 (7.4M معامل)
- رأس المستخدم: 13 طبقة (2048→1024→716→630→430→590→656→235→392→327→364→304→117→52)
  + Skip Connections من متجه الميزات الأصلي (2048) لكل طبقة عبر Linear Projection
  (يحل مشكلة Vanishing Gradient: AUC من 0.519 → 0.966-0.974)
- الإدخال: (2, 128, 128, 128) — قناة1=Intensity، قناة2=Vessel Mask (binary)
